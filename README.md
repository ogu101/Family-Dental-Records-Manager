<h2>Overview</h2>
A Java-based fleet management system for family dental record management. The program supports:

- Input validation for family member counts and teeth types.

- Records upper and lower teeth for each family member.

- Extracts teeth (marks them missing).

- Prints formatted dental records.

- Performs root canal analysis using quadratic formula.
